# Titan BRB Website

Deployable Vite + React website package.

## Run locally
```
npm install
npm run dev
```

## Build
```
npm run build
```

## Deploy
Upload this folder to GitHub, then import the repo into Vercel.

## Adding your real photos
Drop job photos into `public/images/` using the exact filenames listed in
`public/images/README.txt` (e.g. `hero.jpg`, `logo.jpg`, `residential-1.jpg`).
Until a file exists, the site automatically shows a stock placeholder, so the
page never looks broken. Add photos one at a time — no code changes needed.

## What's on the site
- Sticky header with brand mark + Call / Facebook actions
- Hero with stats, Call Now, and Emergency Services buttons
- Six service cards
- **No-Damage Documentation** section (baseline inspections → claim protection)
- Residential project gallery (+ full gallery page)
- Commercial claims panel (+ full gallery page)
- Emergency request form → prefilled email to patrick.tcr@icloud.com
- Footer with contact info (NAP) and service area
- SEO: meta tags, Open Graph/Twitter cards, and LocalBusiness structured data
