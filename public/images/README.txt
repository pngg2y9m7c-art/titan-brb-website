TITAN BRB — Real Photos
=======================

Drop your real job photos into this folder using the EXACT filenames below.
Until a file exists, the site automatically shows a stock placeholder, so the
page never looks broken. The moment you add a correctly-named file and reload,
the real photo takes over. No code changes needed.

Recommended: JPG, landscape, at least 1600px wide, under ~500 KB each.

FILENAMES THE SITE LOOKS FOR
----------------------------
  logo.jpg              -> Titan BRB logo (square works best, ~512x512)
  hero.jpg              -> Big hero image at the top of the home page

  residential-1.jpg     -> Residential roof replacement (active crew/clean jobsite)
  residential-2.jpg     -> Residential roofing inspection / restoration
  residential-3.jpg     -> Residential damage assessment

  commercial-1.jpg      -> Mosaic Church project
  commercial-2.jpg      -> Church exterior
  commercial-3.jpg      -> Commercial roof inspection (technician on roof)

OPTIONAL (used by the "No-Damage Documentation" before/after section):
  before-storm.jpg      -> Roof condition BEFORE (baseline / age-related)
  after-storm.jpg       -> Roof condition AFTER a storm event

HOW IT WORKS
------------
Each <img> first tries /images/<name>.jpg. If that file isn't there yet, it
falls back to the original stock photo. So you can add photos one at a time.
